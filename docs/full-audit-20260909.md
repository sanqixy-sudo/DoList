## 已修复

| 范围 | 原问题 | 现在的行为 |
| --- | --- | --- |
| 磁盘保存 | 保存错误只有日志，退出仍会关闭内存数据库 | 主进程发布失败状态；全局提示重试；保存失败取消退出，保留内存数据 |
| 外键约束 | sql.js 导出之后若磁盘写入失败，重新启用外键的代码可能不执行 | 所有导出使用 finally 恢复外键约束 |
| 任务创建与附件 | 附件/标签失败可留下部分任务，附件缺失被吞掉 | 数据库事务回滚整项创建，清理此次复制的文件，保留源文件以便重试 |
| 永久删除附件 | 数据库删除还未落盘就删除文件，异常退出可造成数据库引用不存在文件 | 删除记录先可靠写入再清理文件；写入失败还原内存记录，支持重试 |
| 任务字段 | 单项更新缺少标题、状态、优先级、日期、目标项目校验 | 非法输入拒绝写入；重复标记完成保留原完成时间 |
| 标签选择 | 小勾选框阻止冒泡但没有切换处理 | 指针和空格均可切换；标签删除失败保持选择并显示错误，成功后更新任务标签缓存 |
| 项目/附件错误反馈 | 部分加载、选择和粘贴错误只有日志 | 项目加载可重试；附件选择、粘贴和打开失败反馈到界面 |
| 专注计时 | 每次回调减一秒，后台延迟造成偏慢；恢复设置后时长不同步 | 用目标时间计算剩余秒数，唤醒完成当前阶段一次，不补算无人值守的多个工作阶段 |
| 专注统计 | 中途改设置可按新时长计入旧会话；跨日统计不及时 | 会话保留开始时的时长；统计跨日重置；相同持久化内容不再每秒写入 |
| 专注交互 | “继续专注”没有继续计时；完成失败无恢复；任务选择器有嵌套按钮 | 继续恢复计时，完成失败留在弹窗重试；明确设为完成；移除嵌套按钮，提供任务搜索 |
| 四象限 | 一次渲染全部卡片和候选；短窗口内容受压；键盘跳转焦点遗漏 | 复用虚拟列表，候选显示前 100 项并提示搜索；短窗口滚动；键盘 End 可以到最后一项 |
| 项目报告 | 完成数/新增数可超过 100%；月度热力图星期错位；切换月份残留日期筛选 | 显示“本期新增完成率”，按本期新增任务中的当前已完成比例计算；星期对齐；周期变化清除日期筛选 |
| 时间线 | 只有计划日期的任务不显示；翻周后仍标“本周”；卡片不能键盘打开 | 加入计划日期事件；显示真实日期范围；支持 Enter/空格打开 |
| 任务详情 | 本地文本值未跟随保存后的标准化内容更新 | 没有未保存草稿时同步最新标题与备注；失败草稿仍保留 |
| 文件与窗口边界 | 附件预览/打开可接收任意路径；外部 URL 无协议限制 | 限制为选择过或已关联的附件；图片预览上限 32 MiB；外链限定 HTTP(S)/mailto；禁止页面导航和新窗口 |

说明：之前的多选单复选框、逐任务间距修复仍然保留，完整多选回归已通过。文字字段没有新增全局“撤销”功能；本轮修复的是编辑框与保存值的同步。

## 性能实测

同一台机器、隔离的 3000 项任务数据。没有清空操作系统缓存，隐藏窗口；不能代表所有设备，也不是严格冷启动基准。

| 指标 | 本轮实测 |
| --- | --- |
| 生产 Electron 新进程启动到任务行出现，3 次 | 694–785 ms，中位数 720 ms |
| 搜索输入到结果出现 | 106–132 ms |
| 切换看板 | 21–54 ms |
| 切换日历 | 29–33 ms |
| 切换列表 | 15–19 ms |
| 主进程读取 3000 项及关联数据，5 次 | 41–59 ms |
| 3000 项重排，5 次 | 21–26 ms |
| 列表跳到底部后等待两帧，3 次 | 34–44 ms，最后任务可见 |
| 列表实际挂载任务行 | 约 15 行 |
| 四象限 UI 场景（1600 多项） | 首屏仅 8 张卡片 |

证据：[`benchmark-current.json`](../.audit/benchmark-current.json)、[`startup-full-audit.json`](../.audit/startup-full-audit.json)。本轮没有宣称所有指标都比上一轮更快；启动存在机器负载和缓存波动。
