# DoList 第一版改版

本次以个人效率为主：默认打开“今天”，日常导航为“今天、收件箱、计划”，项目按组展开，四象限和回顾放在更多工具中。

## 今天与日期

- “今天要做”合并主动加入今日计划和今天到期的待办，同一任务只出现一次。
- 计划日期独立存储。加入今天、修改计划日期或清除计划，都不会改动截止时间。
- 过去的计划与过期任务保留在“待重新安排”，今天完成的任务收进可展开的完成分组。
- 日历优先显示计划日期；没有计划日期时使用截止时间。计划任务显示为全天。
- 四象限仍根据截止时间判断紧急性。仅调整重要性时保留原截止时间；跨紧急程度移动涉及修改截止时间时，先展示具体变更并确认。

## 界面与交互

统一浅色和深色配色、任务行、导航、详情与快速添加入口。宽窗口使用右侧详情栏，窄窗口使用可关闭的详情弹窗。列表、日历、看板、时间线切换时保留当前项目或日常视图范围。

快速添加支持计划日期、截止时间、项目、优先级、标签和附件；提交期间防止重复创建和关闭。标题与备注失焦保存，保存失败保留本次会话中的草稿。搜索提供加载、空结果和失败状态。弹窗与浮层使用短过渡，尊重系统减少动态效果设置。

## 数据与性能

新增 `004_daily_plan` 数据迁移，旧任务保留原截止时间，计划日期初始为空。已有数据库迁移前自动生成旁路备份。文件写入使用临时文件后替换，关闭时保存并清理定时器。

任务集合统一维护，视图只筛选数据；同一任务修改按顺序执行，过期加载结果不能覆盖较新的状态。日历按日期和小时构建索引，日、周、多日视图复用索引，全天任务不再重复进入午夜格。日历、看板、时间线、四象限和回顾按需加载。

本次是核心工作流的第一版。第二轮已补上大列表虚拟滚动、事务批量排序、计划日期分组和性能基准，见 [第二轮改版说明](redesign-v2.md)。完整冷启动测量、数据按需加载及其他视图的完整视觉改版仍待后续推进。

## 运行与验证

安装依赖后运行：

```sh
npm run dev
```

验证命令：

```sh
npm run lint
npm test
npm run test:ui
```

`lint` 检查 TypeScript；核心测试覆盖日期规则、迁移保留、四象限截止时间保留和并发修改。`test:ui` 构建后启动真实 Electron，使用隔离测试数据验证标题保存、计划日期、快速添加、完成任务、项目范围、主题与窄窗口详情，并生成截图。

测试数据库、截图及结果全部写在 `.audit/`，不使用个人数据库。验证脚本会自动退出。未生成发布安装包。
