# 第三轮：日历与看板统一

本轮沿用已有浅色、深色主题和个人效率优先的导航，统一日历与看板的工具栏、卡片、日期信息、详情入口及反馈。

## 看板

- 待办、已完成、已取消三列，保留当前项目或日常视图的任务范围。
- 卡片同时标明计划日期和截止日期，展示备注、优先级和子任务进度。
- 可用鼠标拖动跨列，也可通过卡片的状态选择控件操作。
- 成功后提供上一次状态切换的撤销；恢复历史完成任务时保留原完成时间。任务再次变化后不覆盖新内容。
- 提供当前看板筛选、清空筛选、空列提示和失败重试反馈。更新期间阻止同一任务重复提交。
- 各列独立滚动，长列使用虚拟卡片列表。窄窗口在看板内部横向滚动。

## 日历

- 月、双周、周、三日、日视图共用网格与任务样式，替换四个旧的重复视图模块。
- 月网格根据窗口高度调整单日展示密度；更多任务通过“查看全部”展开。
- 日期展开页支持全部任务、虚拟滚动和键盘首尾导航，点击卡片进入通用任务详情。
- 点击日期格中的添加按钮，或展开页的“添加到这一天”，预填所选计划日期并保留当前项目，截止时间保持独立。
- 全天任务不会重复出现在午夜格，同一时段任务过多时也可展开查看。
- 同一天的全天任务沿用任务排序，避免排序后其他视图仍显示旧顺序。

## 验证

```sh
npm run dev
npm run lint
npm test
npm run test:ui
```

新增检查覆盖看板鼠标拖动、状态切换及撤销、主动注入失败后的重试、筛选空状态、日历展开、五种日期范围、按指定日期与项目添加任务、浅深色及 800×600 窗口布局。

1,500 条任务检查覆盖看板末尾卡片、日历日期展开列表的有限渲染及 Home / End 导航；原有列表和数据迁移测试继续保留。

截图与测试数据库写入本地 .audit/。失败恢复测试会主动抛出一次 Injected update failure，用于检查界面能否恢复；最终以测试退出码和 .audit/ui-results.json 为准。测试不使用个人数据库，本轮没有新增数据库迁移。
